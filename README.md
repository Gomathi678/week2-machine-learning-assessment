# Week 2 Machine Learning Assessment

## Loan Default Prediction

This project focuses on predicting whether a customer is likely to default on a loan using machine learning techniques.

## Tasks Completed

### Task 1 – Exploratory Data Analysis
- Dataset inspection and understanding
- Data cleaning and visualization
- Analysis of important features

### Task 2 – Preprocessing, Features and Pipeline
- Missing value handling using SimpleImputer and KNNImputer
- Categorical encoding using OneHotEncoder and OrdinalEncoder
- Feature engineering
- ColumnTransformer and Pipeline

### Task 3 – Model Building
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- Regression models
- KMeans clustering

### Task 4 – Evaluation and Tuning
- Accuracy, Precision, Recall and F1-score
- Confusion matrix
- ROC curves and ROC-AUC
- Decision threshold selection
- GridSearchCV and RandomizedSearchCV
- Regression evaluation using MAE, RMSE and R²
- Final test evaluation
